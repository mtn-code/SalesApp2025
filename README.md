# Sales Web Application (Scrum project)

In March 2025, I collaborated on a team project to practice working with **Agile methodologies**.
## Contributions
- I took on the roles of **Product Owner**, **Scrum Master**, and **Developer**.
- I wrote a **GitHub guide** for the team (included in the repository).
- After the project was completed, I deployed it to a remote server and ensured the database connection worked properly.

## Project
The project is a Sales **ASP**.**NET** **MVC** Application with following functions:

 - **Login page**
 - **View clients** (both active and non-active), including their type and number of orders.
 - **View orders** with basic details.
 - **View detailed information about individual orders**
